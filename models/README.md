# Models Directory

Stores the on-device acoustic models for jump scare detection and synchronization.

- `silero_vad.onnx`: Silero Voice Activity Detector (~1.5 MB)
- `moonshine-tiny.onnx`: Moonshine-Tiny Speech-to-Text acoustic model (~40 MB) / `whisper-tiny.en.onnx`

Tracked via Git LFS (`.gitattributes`) or downloaded during build.
